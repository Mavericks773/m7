# M7 双账号管理器开发进度

更新时间：2026-09-17

## 当前结果

0.1 开发预览版已具备本地运行条件。程序可在 Windows 上管理两个相互隔离的 Linux Docker 容器，为每个账号保存独立配置、浏览器登录目录、日志、队列、定时计划与运行历史。

## 已完成

- 两个账号槽位与独立持久化目录。
- SQLite 队列、运行记录、每日调度和单账号互斥约束。
- 串行或双并发运行、手动停止、总超时、排队过期与错过补跑。
- 固定官方镜像 RepoDigest，校验 Linux Docker 环境和受管容器标签。
- 容器创建、启动及 Docker 断连后的恢复协调。
- PySide6 桌面界面、二维码、实时日志、托盘与诊断摘要。
- 完整上游配置模板，并开放常用任务、云游戏和超时设置。
- Windows 一键启动脚本、开发依赖和 GPL-3.0 许可证。
- 每账号手选固定清体力副本，支持五种普通副本类型、联动副本目录与每批连续挑战次数。
- 每账号可独立启用培养目标；培养目标与手选固定副本在设置界面中互斥。
- 切换固定副本时显式关闭培养目标、旧体力计划、周本、双倍副本活动和优先合成沉浸器，避免已知目标覆盖。
- 副本设置支持运行中延迟应用、嵌套配置合并、配置冲突检测和每次运行的白名单副本配置摘要。

## 2026-09-17 多副本计划与周本

已实现计划新增、删除、排序、每项次数、扣减／保留模式及明确兜底副本；独立周本支持开关、目标名称和开始星期。设置窗口可滚动，保存按钮固定在窗口底部。

计划最多 20 项、每项 1～999 次。当前上游重试和饰品队伍查找按类型读取 `instance_names`，本版限制同类型使用同一名称并同步恢复映射，兜底与同类型计划保持一致，拒绝同类型不同目标组合。历战余响只走独立周本流程。

运行中由服务层和界面共同阻止计划修改、清空与保留模式切换；未修改计划不会提交旧列表。保存前核对配置指纹，下次运行读取最新的上游剩余次数。独立周本保留普通计划和周本进度时间戳；运行中修改周本仅在下次生效。每次启动摘要包括计划、保留模式和周本目标，业务结果仍标记未确认。

新增固定源码契约夹具及隔离测试，来源为 `b0be473cfd24510d894c96e27964ca52268a80f0`：验证扣减、保留、零执行、异常后续执行、兜底顺序、按类型恢复目标、周本体力与奖励次数、星期门槛和刷新门槛。此结果不等同于镜像或游戏内验收，没有运行真实账号任务。

本轮验证：92 项测试通过，1 项真实 Docker 集成按默认设置跳过；Ruff 与差异空白检查通过；wheel 构建成功并确认包含计划编辑器和 9 个周本目录项。已生成滚动设置窗口预览检查布局；离屏环境缺少中文字形，真实 Windows 字体显示仍以本机启动为准。
