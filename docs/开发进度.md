# M7 双账号管理器开发进度

更新时间：2026-09-14

## 当前结果

0.1 开发预览版已具备本地运行条件。程序可在 Windows 上管理两个相互隔离的 Linux Docker 容器，为每个账号保存独立配置、浏览器登录目录、日志、队列、定时计划与运行历史。

## 已完成

- 两个账号槽位与独立持久化目录。
- SQLite 队列、运行记录、每日调度和单账号互斥约束。
- 串行或双并发运行、手动停止、总超时、排队过期与错过补跑。
- 固定官方镜像 RepoDigest，校验 Linux Docker 环境和受管容器标签。
- 容器创建、启动及 Docker 断连后的恢复协调。
- PySide6 桌面界面、二维码、实时日志、托盘与诊断摘要。
- 完整上游配置模板，并开放常用任务、云游戏和超时设置。
- Windows 一键启动脚本、开发依赖和 GPL-3.0 许可证。
- 每账号手选固定清体力副本，支持五种普通副本类型、联动副本目录与每批连续挑战次数。
- 每账号可独立启用培养目标；培养目标与手选固定副本在设置界面中互斥。
- 切换固定副本时显式关闭培养目标、旧体力计划、周本、双倍副本活动和优先合成沉浸器，避免已知目标覆盖。
- 副本设置支持运行中延迟应用、嵌套配置合并、配置冲突检测和每次运行的白名单副本配置摘要。
